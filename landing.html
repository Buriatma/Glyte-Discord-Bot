❓ Quick FAQ

How do I install Glyte Bot?

Clone the repo, set up a Discord bot token and MongoDB Atlas URI in .env, then run docker compose up -d --build.

Does it need a local MongoDB server?

No. Glyte Bot is designed for MongoDB Atlas, so you can host it anywhere with Docker.

Can I customize commands and rewards?

Yes. The repo includes configurable commands, quests, shop items, and dashboard settings.
